# thawra (طرق استخدام جديدة)

`docs/design/yawm-thawra.html` is written by hand (no build step). It shows four new ways to use the day:
semantic zoom, living outside the app, a thread of beads, and drawing gestures.

`docs/design/yawm-zoom.html` (also by hand) is «قرّب وبعّد», version two: five levels, pinch that follows the fingers, any day of the week, prayers on every part, and a focus level.

`docs/design/yawm-craft.html` (by hand): three calm art directions for the home screen and the «سند» chat (نهار، حبر، منظر).
